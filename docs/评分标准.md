# 颜值评分分项标准

本文档说明 FaceAnalysis 的六维评分体系、权重、打分锚点与总分计算方式。评分由多模态大模型对**单张照片中的面部呈现**给出分项分数，**总分由前端本地加权汇总**，模型不输出总分。

## 一、六个维度

### 1. 面部比例 `proportion`（权重 25%）
- 三庭：发际—眉心—鼻底—下巴 的纵向是否接近三等分。
- 五眼：眼间距、单眼长度与面部宽度的比例是否接近标准范围。
- 关注点：中庭/下庭比值、上庭是否被遮挡、脸宽与眼长比值。

### 2. 对称性 `symmetry`（权重 20%）
- 左右眉高差、左右眼位高低差。
- 嘴角倾斜、下颌角左右差异。
- 关注点：正面角度下的轻微不对称，头部偏转造成的可见差异。

### 3. 轮廓骨相 `contour`（权重 15%）
- 下颌线清晰度、颧骨突出程度。
- 面部折叠度（正面宽度与侧面深度的协调感）。
- 关注点：光线对轮廓层次的影响。

### 4. 五官协调 `harmony`（权重 20%）
- 眼、鼻、唇的相对大小与面部留白比例是否协调。
- **不单独评判某一个器官**，只看整体搭配与留白。

### 5. 肤质状态 `skin`（权重 12%）
- 仅分析照片中可见的肤色均匀度、光泽分布、可见瑕疵。
- 必须注明「这是照片中的肤质表现，不是皮肤诊断」。

### 6. 气质表现 `vibe`（权重 8%）
- 眼神放松程度、表情自然程度。
- **仅做极小幅度加分参考，不做扣分**。

## 二、打分锚点

| 分数区间 | 含义 |
|---------|------|
| 90–100 | 该维度接近典型审美模板的参考范围 |
| 70–85 | 大多数普通照片的集中区间 |
| 60–69 | 与参考范围有明显偏离 |
| < 60 | 明显偏离，或照片质量导致难以评估 |

照片质量差（模糊、严重侧脸、遮挡、光线极差、分辨率过低）时，应在对应维度如实说明并适当降分。

## 三、每个维度的输出字段

模型对每个维度返回四个字段（均控制在简短一句话内）：

- `score`：0–100 整数。
- `observed`：可验证的客观描述（如「中庭略长，眼距适中」）。
- `deduction_reason`：极简扣分逻辑（如「中庭偏长→扣 8 分」）。
- `photo_advice`：与扣分一一对应、可操作的拍照角度/光线建议。

此外还返回：`image_quality`（照片质量等级与说明）、`photography_tips`（光线/角度/表情/构图分类建议）。

## 四、总分计算（本地）

总分由前端按下式计算，模型不参与：

```
总分 = proportion×0.25 + symmetry×0.20 + contour×0.15
     + harmony×0.20 + skin×0.12 + vibe×0.08
```

权重之和为 1.0，结果四舍五入取整，并映射评级：

| 总分 | 评级 |
|------|------|
| ≥ 85 | S · 卓越 |
| 75–84 | A · 优秀 |
| 65–74 | B · 良好 |
| 55–64 | C · 一般 |
| < 55 | D · 有待提升 |

## 五、语言与合规约束

- 语言克制、具体、非评判性；使用「偏长/偏短/偏宽/偏移/不清晰」等描述词。
- 禁止「丑/差/缺陷/完美」等主观价值判断词。
- 只给拍照、光线、角度、表情、构图建议，**不涉及任何医疗或美容项目**。
- 只基于当前上传的单张照片。

## 六、提示词演进

- `note.md`：早期设计稿，六维扣分制 + 拍照建议，强调「禁止模型给最终分」。
- `note2.md`：加权制设计稿，明确各维度权重与「观察→参考→差距→扣分」的输出范式。
- 当前实现融合两者：六维加权、模型只出分项、本地汇总总分、文案单行精简。
