# 使用说明

## 一、准备工作

`index.html` 与 `html2canvas.min.js` 必须放在**同一目录**（图片导出功能依赖后者）。

推荐用本地服务器打开以获得最佳相机体验：

```bash
cd faceanalysis
python -m http.server 8000      # 访问 http://localhost:8000
# 或
npx serve .
```

也可以直接双击 `index.html` 用浏览器打开（系统相册/相机选择通常仍可用，但个别浏览器对 `file://` 调用摄像头有限制）。

## 二、配置接口

首次打开会自动弹出「接口设置」。填写三项：

- **API Base URL**：OpenAI 兼容接口基址，例如 `https://api.deepseek.com`。程序会自动补全为 `.../v1/chat/completions`。
- **API Key**：你的密钥。
- **模型名称**：必须支持图像输入，例如 `deepseek-flash`。

点「测试连接」验证可用性，点「保存」写入本机浏览器 `localStorage`。这些信息**只存在你自己的设备上**。

> 不想配置？点弹框底部「跳过 · 体验演示评分」，即可用随机数据体验完整流程（报告会标注「非真实结果」）。

## 三、拍照与分析

1. 主页点「选择」→ 系统相机拍照或从相册选一张**免冠正脸、光线均匀、无遮挡**的照片。
2. 选好后点「分析」。
3. 期间只显示分析动画；照片在本地去除隐私元数据后才上传，模型返回六维分项，总分由本地计算。
4. 完成后进入报告页。

## 四、查看与导出报告

报告页包含：综合总分与评级、六维得分条、分项详情（观察/扣分/建议）、拍照建议、整体点评。

- **保存图片**：把整页报告导出为 PNG。
- **导出文本**：导出含全部文字的 `.txt`。
- **再测一次**：返回主页重新选图。

文件名带版本号后缀，如 `颜值分析报告_82分_v1.0.0.png`。

## 五、横屏 / 竖屏

- 竖屏：单栏自上而下。
- 横屏（宽度 ≥ 820px）：左右两栏，左侧照片+总分+分项条，右侧详情+建议+点评。旋转设备会自动重排。

## 六、常见问题

**Q：分析失败 / 报跨域错误？**
接口未开启 CORS 或 Base URL/Key/模型名有误。用「测试连接」排查；确认模型支持图像输入。

**Q：模型返回了总分？**
不会。提示词已硬性禁止模型输出总分，总分只在前端本地计算。

**Q：保存图片只有背景或空白？**
极少数旧 WebView 对截图支持有限，会自动回退到文本导出。也可改用系统截屏。

**Q：勾选/结果会保存吗？**
配置（URL/Key/模型、演示开关）保存在 `localStorage`，清除浏览器数据即删除；评分结果不落盘，仅当前会话展示或手动导出。

**Q：DeepSeek 该选哪个模型？**
选 `deepseek-flash`（支持图像）。不要用 `deepseek-v4-pro`（不支持图像，会返回全 0）。

## 七、隐私与安全

- 照片在设备本地经 Canvas 重绘，剥离 EXIF/GPS/时间戳后仅上传必要像素。
- 接口密钥仅存本机 `localStorage`，不上传任何服务器。
- 请仅上传你本人或已获授权的照片。
- 若在公共/共享设备上使用，记得清除浏览器数据以删除保存的密钥。
